# 🚀 Shackleton Camp — Simulador de Exploración Lunar

Videojuego educativo 3D en perspectiva isométrica desarrollado en **Unity 6 (URP)** para dispositivos móviles Android. Explora la base lunar *Shackleton Camp*, interactúa con terminales científicas y completa misiones de campo.

---

## 📱 Cómo descargar e instalar el APK (Android)

1. Ve a la sección **[Releases](https://github.com/pablo-mald03/proyecto-nave-exploracion/releases)** a la derecha de este repositorio (o haz clic en la última versión publicada).
2. Descarga el archivo **`ShackletonCamp_v1.0.apk`** directamente en tu teléfono Android.
3. Abre el archivo descargado desde tu gestor de archivos o notificaciones.
4. Si Android lo solicita, habilita la opción **"Instalar aplicaciones de orígenes desconocidos"** para tu navegador o explorador de archivos.
5. Presiona **Instalar** y abre **Shackleton Camp**.

---

## 🛠️ Cómo abrir y ejecutar el proyecto en Unity

### Requisitos previos
* **Unity Hub** con **Unity 6** (con el módulo **Android Build Support** instalado: SDK, NDK y OpenJDK).
* **Git LFS** habilitado para la descarga correcta de modelos 3D (`.fbx`), videos (`.mp4`) y texturas.
